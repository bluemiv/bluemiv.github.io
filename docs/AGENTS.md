# docs 규칙

- 문서는 현재 구현과 일치해야 한다.
- 디자인 결정 변경 시 `design-system.md`를 같은 커밋에서 갱신한다.
- 이름·경로·용어 변경 시 `naming-conventions.md`를 갱신한다.
- 검색 노출 대상이나 sitemap, feed, robots 규칙 변경 시 `seo.md`를 갱신한다.
- 구현된 현재 상태만 기록한다. 계획과 추측을 규칙처럼 쓰지 않는다.
- 같은 규칙을 여러 문서에 복사하지 않는다. 단일 기준 문서를 link한다.
- 문장은 짧고 명확하게 쓴다. 중복 설명을 피한다.
- 문서 파일명은 소문자 kebab-case.
- 코드·경로·명령어는 실제 존재 여부를 확인한다.
