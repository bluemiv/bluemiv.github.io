# policy 규칙

- 기존 Privacy Policy, Terms, Account deletion 공개 URL을 유지한다.
- 법적 문구를 임의로 요약하거나 새로 만들지 않는다.
- 실명, 개인 전화번호, secret을 넣지 않는다.
- 공개 연락처는 `public.bluemiv@gmail.com`을 사용한다.
- 이관 HTML은 script, event handler, inline style을 허용하지 않는다.
- policy 화면은 읽기 폭, heading, list, link만 명확하게 표현한다.
- policy에 광고, sidebar, 과한 장식, 앱 목록 navigation을 넣지 않는다.
- policy metadata는 `noindex, follow`를 유지하고 sitemap과 feed에서 제외한다.
- 경로 추가·변경 시 route 생성 테스트와 기존 URL 목록을 함께 갱신한다.
